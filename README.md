# Doubly Robust Estimation of Causal Survival Effects via IPT-IPC Weighting and Semi-Parametric AFT Models with Variable Selection

This repository contains the R code used for the simulation studies and real data analysis presented in the manuscript:
Doubly Robust Estimation of Causal Survival Effects via IPT-IPC Weighting and Semi-Parametric AFT Models with Variable Selection

The code implements a doubly robust estimation framework with variable selection and includes all scripts necessary to reproduce the main numerical results.


1. Main R Functions for Proposed Estimators

     This file contains the main R functions implementing the proposed estimators for the average causal effect (ACE) described in the manuscript. The functions allow users to estimate the ACE under the proposed framework
     by providing the required input data and model specifications.

2. Main R Functions for Variable Selection

     This file contains the R functions developed for variable selection under the proposed model. These functions implement the variable selection procedure described in the manuscript and can be used to identify important
     covariates for subsequent ACE estimation.

4. Simulations – Proposed ACE Estimators

     This file contains the simulation code used to evaluate the performance of the proposed ACE estimators. 

4. Simulations – Variable Selection

     This file contains the simulation code used to assess the performance of the proposed variable selection procedure. 

5. Real Data Analysis

     This file contains the code used to analyze the real-world dataset presented in the manuscript.
